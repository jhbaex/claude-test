# todo-guard 설치

## 설치

`todo-guard` 폴더를 아래 위치에 통째로 넣는다.

```
Windows   C:\Users\<사용자>\.claude\skills\todo-guard\
macOS     ~/.claude/skills/todo-guard/
```

Claude Code 를 다시 열면 스킬 목록에 잡힌다.

## 쓰는 법

프로젝트 폴더에서 한 번만 실행.

```
투두가드로 프로젝트 세팅해줘
```

세팅이 끝나면 `/exit` 로 나갔다 다시 들어온다. 훅은 세션을 열 때 읽힌다.

## 무엇이 생기나

| 파일 | 하는 일 |
|---|---|
| `TODO.md` | 받은 지시를 적어 두는 곳 |
| `.claude/hooks/` 4개 | 스킬 본체를 부르는 껍데기 |
| `.claude/settings.json` | 훅 등록 |
| `.claude/todo-guard.json` | 문서 규칙 ON / OFF |
| `CLAUDE.md` | 운영 규칙 병합 |

## 하는 일

**1. 작업 누락 방지** — 지시를 TODO.md 에 적고, 미완료가 남으면 턴 종료를 막는다.

**2. 문서 문체 검사** — 슬라이드·보고서를 만들 때 규칙을 적용하고,
다 쓴 뒤 바뀐 줄을 검사한다. 위반이 있으면 턴 종료를 막는다.

## 명령

| 사용자가 말하면 | 하는 일 |
|---|---|
| 전체 검수해줘 | 폴더의 문서 전부 검사 |
| 바뀐 것만 검수해줘 | 직전 검사 뒤 바뀐 줄만 |
| 문서 규칙 꺼줘 / 켜줘 | 문서 검사 ON / OFF |
| 검사 규칙 보여줘 | 규칙 22종 출력 |

## 규칙을 고치려면

| 무엇 | 파일 | 고치면 |
|---|---|---|
| 쓰기 전 가이드 | `rules/doc-rules.md` | 즉시 적용 |
| 검사 규칙 22종 | `rules/harness-rules.md` | 즉시 적용 |
| 세션 밖 편집 규칙 | `rules/outside-rule.md` | 전역 CLAUDE.md 에 설치 |

`rules/harness-rules.md` 의 코드 블록에 `이름 = 정규식` 한 줄을 더하면 규칙이 늘어난다.
줄 앞에 `#` 을 붙이면 해당 규칙만 꺼짐. 파이썬 수정 불필요.

## 필요한 것

- Python 3
- `python-pptx` — `.pptx` 를 검사할 때만 필요 (`pip install python-pptx`)

## 검사 범위

문체와 워딩만 검사. 배치(글자 넘침·여백)와 정직성(지어낸 수치·캡처)은 검사 대상 밖.
배치와 정직성은 프로젝트마다 기준이 달라 프로젝트 자체 하네스에서 담당.

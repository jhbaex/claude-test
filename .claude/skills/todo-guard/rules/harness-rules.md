# 하네스 규칙 (todo-guard)

`scripts/doc-guard.py` 가 **이 파일을 읽어** 검사한다.
아래 목록을 고치면 다음 검사부터 바로 적용된다. 파이썬을 고칠 필요가 없다.

## 고치는 방법

- **규칙을 더한다** — 목록에 `이름 = 정규식` 한 줄을 추가한다
- **규칙을 끈다** — 줄 맨 앞에 `#` 을 붙인다. 지우지 말고 남겨 두면 되살리기 쉽다
- **오탐을 줄인다** — 정규식을 좁히지 말고 예외를 덧붙인다.
  좁히면 그 자리로 진짜 위반이 다시 새어 나간다
- **확인** — `python scripts/doc-guard.py --rules` 로 읽힌 규칙을 확인한다.
  정규식이 잘못되면 그 줄만 건너뛰고 어디가 잘못됐는지 알려 준다

정규식은 파이썬 문법을 쓴다. 세로줄(`|`)이 많아 표가 아니라 코드 블록에 적는다.

## 1. 금지어

횟수와 무관하게 한 번도 쓰지 않는 낱말.

```
자리
```

## 2. 상투어

뜻이 흐릿해 말버릇이 되기 쉬운 낱말. 한도를 넘으면 위반으로 본다.

```
한도: 8
부분 경우 상황 지점 대목 측면 모습 존재 위주 바탕 차원 관점
사항 내역 여부 정도 범주 영역 느낌 식으로
```

## 3. 본문 규칙

`이름 = 정규식` 형식. 한 줄에 하나씩.

```
지시대명사 = (?<![A-Za-z0-9])(?<![A-Za-z0-9]\s)(^|[\s(\[「])(이|그|저)\s+(?!하는|하면|하고|되는|되면|각각|모두|아니|없|있|같|많|적|크|작|맞|틀|바로|다시|더|또)[가-힣A-Za-z]
지시대명사2 = (^|[\s(\[「])(여기|거기|저기|이곳|그곳|이때|그때|이런|그런|저런|이것|그것|저것)(?![가-힣])
지시대명사3 = (^|[\s(\[「])(여기|거기|이곳|그곳|이때|그때)(에서|에는|서|는|에)(\s|$)
합쇼체 = [가-힣](습니다|ㅂ니다)\s*[.!?]?\s*$|[가-힣]니다\s*[.!?]?\s*$|[가-힣](십시오|시오)\s*[.!?]?\s*$
```

**잡는 예**

| 이름 | 잡는 예 |
|---|---|
| 지시대명사 | 이 폴더에서 · 이런 방식으로 · 여기에서 시작 |
| 평서형 종결 | 값을 본다 |
| 해요체 | 오래 걸리지는 않아요 |
| 구어 낱말 | 그냥 넘어감 · 진짜 오래 |
| 강조부사 구어 | 전혀 안 만듦 |
| AI 말투 | 효과적으로 동작한다고 할 수 있음 |
| 번역투 | 방식을 통해 · 품질에 대해 |
| 비유 과다 | 뼈대를 잡음 |
| 이중조사 | 그의 의 뜻 |
| 영어투 것이다 | 좋을 것이다 |
| 한글 수사 | 여덟 개이며 · 훅 세 개 |

「안 · 못 + ㅁ받침 명사형」(안 엉킴 · 못 봄)은 받침을 따져야 해서 정규식으로 적지 않는다.
검사기에 붙박이로 들어 있다.

## 4. 제목 규칙

제목에만 적용한다. `#` 으로 시작하는 줄, 그리고 조사·불릿이 없는 짧은 줄을 제목으로 본다.

```
제목 의문형 = (인가|은가|는가|할까|나요|하나요)\s*$|(주나|보나|되나|있나|쓰나|가나|오나)\s*$|\?
제목 서술 종결 = (있다|없다|된다|한다|않다|같다|맞다|아니다)\s*$
제목 관형절 구어 = 하는\s*(법|방법)\s*$|(어야|아야|여야)\s*할\s|^지금\s|칠\s*것\s*$|어떻게|무엇을
```

**잡는 예** — 무엇을 대신해 주나 · 더 있다 · 지금 있어야 할 폴더

## 5. 검사 대상

| 항목 | 값 |
|---|---|
| 읽는 확장자 | `.md` `.txt` `.pptx` |
| 검사 제외 파일 | `TODO.md` `CLAUDE.md` `README.md` |
| 검사 제외 폴더 | `.git` `node_modules` `__pycache__` `.venv` `교정` `.claude` |

`.pdf` `.doc` `.hwp` 는 직접 읽지 않는다. `.pptx` 나 원고에서 만들어지므로 원본을 검사한다.

## 6. 검사에서 빼는 줄

화면에 그대로 찍히는 것은 문체 규칙 대상이 아니다.

- 터미널 출력·명령·코드 (`PS ` `> ` `$ ` `#` `|` 로 시작하는 줄)
- 오류 메시지 원문 (`경로를 찾을 수 없습니다` 등)
- `.pptx` 에서는 어두운 창 안의 글, 고정폭 글꼴로 찍은 글, 한글이 없는 줄
